<h1 align="center">
CAR MOVEMENT
</h1>

> 2D Top down game

### Tech

- `Vite` : module bundle untuk mengambil assert HTML
- `TypeScript` (javascript) : Untuk Logic aplikasi

### Ide

- mobile hanya bergerak kiri kanan
- X tidak bisa mundur
- object lain yang bergerak ke bawah saat mobile bergerak ke depan
- File Html akan di fetch oleh JS ke Index.html sebagai file utama

### Key binding

- arrow up : mobil bergerak kedepan (sebenarnay object yang bergerak mundur )
- arrow left : mobil bergerak ke kiri
- arrow right : mobil bergerak ke kanan

### footer info

- `y koordinat` : posisikan mobile dari koordinat y (vertikal)
- `active` : pakai kontroller jika di android
- `switch` : masuk ke perubahan perpektive ( jadi gepeng tapi wkwkw)
  > yang gepeng adalah canvas, jadi semua element di dalamnua akan mengikuti
